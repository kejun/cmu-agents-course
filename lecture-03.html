02

两大挑战：容量与效率

Capacity 容量
  • 模型能用上需要的证据吗？
  • 架构、位置编码、训练塑造「可用上下文」
  • 评测衡量它：needle-in-a-haystack 等
Efficiency 效率
  • 系统供得起吗？
  • Attention、KV 记忆、缓存、压缩塑造成本与延迟
  • 决定 Agent 的每次调用花多少钱、等多久

两者互锁：架构决定容量上限，服务栈决定成本曲线，而 Agent 的实际体验是二者叠加的结果。

💡 广告上下文 ≠ 有效上下文
模型文档宣称的上下文长度（如 128K）往往远高于实际可用长度。GPT-4 的 needle-in-a-haystack 评测（Kamradt 2023）显示：在长上下文中找一根「针」，即便在声明范围内也常失败。评估容量要用评测，不能看参数表。

服务指标：TTFT 与 TPOT

TTFT

首 token 延迟

请求到达 → 第一个 token 输出。由 Prefill 主导——上下文越长，TTFT 越长。

TPOT

相邻输出间隔

两个输出 token 之间的间隔。由 Decode 主导，是「打字速度」。

Throughput

吞吐

单位时间完成的 tokens / 请求数。

Cost

成本

input + cached input + output 三项分别计费。

⚠️ 长上下文的代价藏在 Prefill 里
历史从 10K 涨到 100K，TTFT 几乎线性恶化，同时每轮都在为重复处理相同的历史付费——这就是 KV 缓存存在的根本原因。
04

注意力复习

因果自注意力（Causal self-attention） Q = X·W_Q K = X·W_K V = X·W_V # 线性投影 A = softmax( QKᵀ/√d_k + M ) # M: j>i 时为 −∞（遮未来） O = A·V

X ∈ ℝⁿˣᵈ 的每一行是一个 token 状态 zₜ；qᵢ, kⱼ, vⱼ 是 Q/K/V 的行。每个 query 都和全部历史 key 做两两比较——这正是「全局」注意力的成本来源。

05

长上下文架构：四种机制

① Sliding window 滑动窗口

只看局部 w 个位置

因果窗口掩码 M⁽ʷ⁾：仅 0 ≤ i−j < w 可见。计算从 O(n²) 降到 O(wn)。代价：局部层无法直接取回远端 token。Longformer 2020 ↗

② Linear / Recurrent 线性循环

固定大小的状态矩阵

用双线性分数替代 softmax，重结合求和顺序，得到定长循环记忆 Sₜ。显式 token 级访问消失，变成在线更新的状态。谱系：Softmax → Linear → DeltaNet → Gated DeltaNet → KDA。

③ Sparse attention 稀疏注意力

只对一部分 key 做比较

固定模式（Longformer：局部窗 + 全局锚点）或内容相关（TopK 选择器）。预测成本 vs 自适应检索——选择器出错会漏掉相关 key。

④ KV compression KV 压缩

压缩缓存潜变量

MLA（DeepSeek-V2）：只缓存压缩后的潜变量 cᵏᵛ，运行时重建每头 K、V。缓存变小，注意力数学不变。

线性注意力的进化谱系

五种方案沿同一目标递进：把「记住全部 token」换成「维护一个定长记忆」。

Softmax → Linear → DeltaNet → Gated DeltaNet → KDA

→ 重结合顺序
Linear

→ 目标修正
DeltaNet

→ 标量遗忘
Gated ΔNet

→ 逐通道遗忘
KDA
每特征寿命

Linear（Katharopoulos et al., ICML 2020）

把求和顺序重结合成循环 oₜ = Σᵢ softmax(qₜᵀkᵢ/√dₖ) vᵢ ⟶ 用双线性分数 qₜᵀkᵢ 替换 softmax 权重 ⟶ oₜ = Sₜ qₜ, 其中 Sₜ = Σᵢ kᵢvᵢᵀ Sₜ = Sₜ₋₁ + kₜ vₜᵀ # 固定大小记忆，在线累加

加法写入的问题：干扰无法显式擦除——旧关联一直存在。

DeltaNet（Schlag et al., ICML 2021）

目标修正：只写预测误差 v̂ₜ = Sₜ₋₁ᵀ kₜ # 当前记忆对 kₜ 的预测 eₜ = vₜ − v̂ₜ # 预测误差 Sₜ = Sₜ₋₁ + βₜ kₜ eₜᵀ # 只沿 kₜ 方向修正，无关记忆保留 oₜ = Sₜᵀ qₜ

Gated DeltaNet（Yang et al., 2024）

先整体衰减，再做目标修正 S̃ₜ₋₁ = αₜ Sₜ₋₁ # αₜ∈[0,1] 标量保留门：全局遗忘 Sₜ = S̃ₜ₋₁ + βₜ kₜ (vₜ − S̃ₜ₋₁ᵀkₜ)ᵀ # 设 αₜ = 1 即退化为 DeltaNet

Kimi Delta Attention · KDA（Kimi Team, 2025）

逐通道遗忘：每个特征有自己的寿命 Dₜ = Diag(αₜ) # αₜ∈[0,1]ᵈ 向量保留门 Sₜ = (I − βₜ kₜ kₜᵀ) Dₜ Sₜ₋₁ + βₜ kₜ vₜᵀ # 各通道等保留 ⇒ 退化为 Gated DeltaNet
💡 进化主线
每一代解决上一代的一个缺陷：Linear 引入定长状态 → DeltaNet 学会定向纠错 → Gated 学会忘记旧的 → KDA 细粒度到每个特征维度。GLM-5.3-Flash 与 Kimi K3 都是 KDA 路线的受益者。
07

稀疏注意力与 KV 压缩

固定模式稀疏
  • 掩码与输入无关：Sᵢ = 局部窗 ∪ 全局锚点
  • 成本可预测，但模式不能随 query 自适应
  • 示例：Longformer 的 sliding window + global tokens
内容相关稀疏（TopK）
  • 选择器按 query 挑最相关的 K 个 key：Sᵢ = TopK(g(qᵢ, kⱼ))
  • 自适应检索，选择器出错会漏掉相关证据
  • 示例：DeepSeek Sparse Attention (2025)

KV 压缩：MLA（DeepSeek-V2, 2024）

缓存潜变量，重建每头 K/V cₜᵏᵛ = Wᴰ zₜ # 压缩：只缓存这个潜变量 kₜ⁽ʰ⁾ = Wᵁᴷ⁽ʰ⁾ cₜᵏᵛ # 解码时按头重建 Key vₜ⁽ʰ⁾ = Wᵁⱽ⁽ʰ⁾ cₜᵏᵛ # 解码时按头重建 Value

GQA 让多个 head 共享 K/V 缓存；MLA 更进一步——缓存一个低秩潜变量，运行时解压。内存占用大降，注意力方程不变。

位置编码三路线

绝对编码

Absolute

zₜ = E[xₜ] + pₜ

sinusoid 解析定义或学习表。外推困难——长度超出训练范围位置向量没见过。

Vaswani et al., 2017

相对旋转

RoPE

q̃ᵢ = R(i)qᵢ

旋转 Q/K 行，分数只依赖相对位移 j−i。可插值扩展（PI / YaRN）。

Su et al., 2024

无显式编码

NoPE

zₜ = E[xₜ]

顺序由因果计算本身编码，或由循环动态推断。无外推问题，但仍需训练长程行为。

Kazemnejad et al., 2023

位置插值：PI 与 YaRN

PI 均匀插值（2023）
  • 把目标位置 t 映射回熟悉相位 t/s（s = L′/L）
  • 每个 RoPE 维度拉伸同一比例：R(t) → R(t/s)
  • 长位置不超出预训练相位范围
YaRN 频率选择性（ICLR 2024）
  • 长波维度完全插值；短波维度保持局部相位；中间混合
  • 加注意力温度 τ 修正熵漂移：softmax(QKᵀ/τ√dₖ)
  • τ ≈ 0.1·ln s + 1（LLaMA 拟合配方，非普适常数）

上下文并行（Context parallelism）

把超长序列切成块分到 P 个设备：每设备记忆 O(ndₖ/P)，通信与块注意力重叠，总计算量仍是精确的 O(n²dₖ)——不是近似。代表：Ring Attention（Liu et al., 2023）、Megatron CP。

上下文压缩：Compaction

缓存只省成本，不省容量。当历史超过窗口，需要压缩：把长历史折叠成简洁的工作状态。

压缩示例：真实 CI 排障会话

压缩前（原始历史）
OBSERVATION CI job 30 分钟后超时。 ACTION 检查 job 日志。 OBSERVATION 24K 行日志，反复出现 “address already in use”. ACTION 设 --workers=1 重跑。 OBSERVATION 套件通过；日志存于 /tmp/ci.log。
压缩后（工作状态）
OBSERVATION 目标：修复 CI 超时。 原因：端口冲突。 已验证：--workers=1 通过。 证据：/tmp/ci.log。 NEXT ACTION 用验证过的 worker 配置开 PR。

压缩 = 状态估计

形式化 ŝₜ = 𝒞(Hₜ; B) # 压缩器：历史 → 工作状态，受预算 B 约束 |ŝₜ| ≤ B # 状态有界 p(A_future | Hₜ) ≈ p(A_future | ŝₜ) # 行为保真：未来动作分布近似不变

思考题

Q1 · 成本核算
对比「勉强塞进窗口」和「每轮主动压缩」两种策略：在 100K 历史的会话里，各需要多少 input tokens？缓存定价下哪种更划算？
查看参考思路
不压缩：每轮携带 100K 增长输入，且 KV 缓存前缀抖动会频繁重新 prefill。主动压缩：稳定 ~10K 前缀 + 增量，命中缓存按 1/10~1/40 价计费。长会话中压缩策略几乎必然胜出——但需付出信息损失风险。
Q2 · 架构选择
KDA 相比 Gated DeltaNet 改进了什么？为什么「逐通道遗忘」比「整体衰减」更能保留有用记忆？
查看参考思路
Gated DeltaNet 用一个标量 αₜ 衰减整个状态——忘记旧信息时无法区分哪些维度该留。KDA 用向量门 αₜ∈[0,1]ᵈ 给每个 key-space 特征独立寿命，能保留长期重要的通道同时清掉噪声，相当于更精细的「记忆管理」。
Q3 · 压缩策略设计
你负责给一个 Agent 框架写压缩策略。哪些内容必须「原样」保留而非「总结」？
查看参考思路
目标/约束（anchors）、精确 ID/路径/版本号、最近的活跃尝试。总结会丢精度与约束，如 "CUDA 12.4" 变 "recent CUDA"。文件/日志等大块证据应外化到可检索存储，而非塞进摘要。
Q4 · 缓存工程
你的 Agent 每轮输出都带时间戳，导致缓存命中率骤降。怎么修？
查看参考思路
把时间戳从稳定前缀移出：要么放到轮次末尾（追加区），要么在注入前统一替换占位符。保持 system/tools/演示前缀字节级稳定；测量 cached tokens 验证修复。
