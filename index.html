这门课的核心视角

Building

如何构建

Agent = 模型在循环中。最小实现只有 20 行：一个 run 循环，交替调用模型与执行动作。

Evaluating

如何评估

从工具选择的准确性到任务完成率、从 token 成本到延迟。好的评估应该能定位失败发生在哪个环节。

Training

如何训练

预训练 → 中间训练 → SFT → RL 的完整链路；何时用训练解决、何时用 harness 工程解决。

Safety

如何保证安全

工具权限最小化、沙箱隔离、人为审批不可逆动作、防止提示注入跨越安全边界。

Research

研究前沿

每讲锚定最新论文：XGrammar、MLA、SkillsBench、ASI、RAO、MACU、R2E-Gym…… 打开论文原文。

Perspective

产品视角

面向 Agent 产品开发：上下文预算、缓存命中设计、技能维护、规划与人工审批的平衡。
